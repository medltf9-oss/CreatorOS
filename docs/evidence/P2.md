## b. Decisions

- **One `UtcDateTime` type decorator** stores naive UTC and always returns tz-aware UTC, so
  "naive datetime" bugs cannot reach the database (rejected with `ValueError`).
- **Enum-as-CHECK**: SQLite has no native enums, so each enum becomes VARCHAR + CHECK,
  giving database-level rejection of invalid states as well as Python-level validation.
- **Queue idempotency is scoped to open jobs**, while `publish_job.idempotency_key` is
  UNIQUE forever. That separation matters: a completed backup may legitimately be
  re-requested, but a published post must never be re-created.
- **Worker errors are classified**: `ValueError` from a handler is non-retryable (dead
  letter immediately); other exceptions retry with backoff. Handlers receive a read-only
  `_JobView`, so a handler cannot mutate the queue row it is executing.
- **Backups use `closing()`**, not `with sqlite3.connect(...)`: the latter commits but does
  not close the file handle, which made pruning fail with `PermissionError` on Windows.
- **No fake agents / no fake publishing**: `/agents/catalog` is genuinely empty until
  Phase 4 and every unimplemented capability is reported as such by `/version`.

## f. Defects found and fixed in this phase

| Defect | Fix |
|---|---|
| Autogenerated migration referenced `UtcDateTime` without importing it | Patched `script.py.mako` + revision; documented in code comment |
| Relative imports wrong at three package depths (`..db`, `.deps`) | Corrected to `...db`, `..deps` with import-time verification |
| `/version` was unauthenticated | Added `Depends(require_token)` |
| Tests shared one database and saw each other's rows | Added per-test table cleanup fixture |
| Cross-session tests hit `database is locked` | Commit before opening a second session (single-writer reality) |
| `VACUUM INTO` failed when two backups hit the same second | Microsecond timestamp + random suffix |
| `verify()` raised on a corrupt file instead of reporting | `sqlite3.Error` caught → `ok: false` |
| Pruning failed with `PermissionError` (open handles) | `contextlib.closing` around every sqlite connection |
| `with sqlite3.connect()` used as if it closed the file | Replaced everywhere; test now proves pruning works |

## g. Functional vs not implemented

**Functional:** 31-table schema with reversible migrations; 36 typed endpoints; token auth +
origin allowlist + security headers + body cap; audit trail on every write; durable queue with
recovery guarantees; background worker executing real jobs; local backups with integrity
verification and restore drill; structured logs with proven redaction.

**Not implemented (by plan):** model gateway/governor (P3), agents (P4), video intake (P5),
OAuth (P6), publishing (P7), analytics (P8), design system (P9), installer (P10).
`POST /accounts/oauth/{platform}/start` returns **501** with an explicit reason and the UI
reports `oauth: not implemented` — no control pretends to work.

# Activation evidence

The record behind `docs/OPERATIONAL_ACTIVATION.md`. Same discipline as `docs/evidence/P10.md`: the four
classifications stay apart, and nothing here is asserted without the command that produced it.

* **Implemented** - the path exists and is reachable.
* **Fixture tested** - a test drives it with a mocked provider.
* **Real provider tested** - a live call reached the provider, and the answer is quoted.
* **Blocked** - an external grant, credential or approval this machine does not have.

At the end of this phase there is still **no real-provider row**: no Meta app, no TikTok app, no
connected account, no delivery bucket, no code-signing certificate. What changed is that the local
layer is now real-provider tested against Ollama, which is a real provider, and every product-side
path is measured on the installed app rather than assumed.

## C. OAuth listener, exercised on the installed app without a provider

Nothing here contacts Meta or TikTok; it proves the local half of the flow behaves and refuses
correctly.

| Request | Status | Page text |
| --- | --- | --- |
| `GET /not-a-callback` | 404 | "This address only accepts OAuth callbacks." |
| `GET /oauth/callback/nope` | 400 | "This callback path is not one of ours." `UNKNOWN_ROUTE` |
| `GET /oauth/callback/facebook_login?error=access_denied&error_description=user+cancelled` (no state) | 400 | `STATE_INVALID` — an untrusted response is not correlated, by design |
| `GET /oauth/callback/tiktok_login?code=abc&state=forged` | 400 | `STATE_INVALID` |
| `GET /social/oauth/transactions` | 200 | one historical `failed` row (`MIGRATION_VERIFIER_UNRETRIABLE`); nothing new was created |

A provider denial **with** a valid state is handled separately and fixture-tested:
`tests/test_social_oauth.py::test_user_denial_is_reported_not_swallowed` asserts
`AUTHORIZATION_DENIED` and that no account is created.

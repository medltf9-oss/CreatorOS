## Three real bugs found by running the app (and fixed)

These were invisible to the test client and would have shipped broken:

1. **Signed media URLs returned 401 in the browser.** The four byte-serving routes were
   mounted behind the session-token dependency, but `<img>`/`<video>` cannot send an
   `Authorization` header. They now live on a separate router authorized only by the HMAC
   signature. Test: `test_signed_media_urls_work_without_a_bearer_token`.
2. **Every thumbnail URL resolved to the Vite origin.** `thumbnail_url` is API-relative; the
   renderer runs on `http://localhost:5173` in development and `file://` when packaged.
   `LibraryApi.mediaUrl()` now resolves against the API base.
3. **CSP and CORP blocked the image bytes.** `img-src`/`media-src` did not allow
   `http://127.0.0.1:*`, and the global `Cross-Origin-Resource-Policy: same-site` header
   blocked cross-origin embedding. Both fixed; a test asserts the CORP header.

Two smaller truthfulness fixes came from the same runs: progress reported **100 % on the first
line** (FFmpeg's `out_time_ms` is microseconds — now parsed as such, with a guard against
absurd samples), and the Storage page claimed a 5 GB floor while the policy is 1 GB (now read
from the backend).

## Known limitations, stated

* **No hardware encoding on this machine** — measured, documented, surfaced in the UI.
* **One FFmpeg at a time** — deliberate; a second concurrent encode would starve the AI
  governor on 4 cores.
* **Timeline frames are capped at 40** and scene scan at 30 scenes / 25 s: bounded work, not a
  full shot-detection engine.
* **Thumbnail choice is a heuristic** (luma + chroma variance). A clip that is dark everywhere
  still gets a dark frame; the chosen timestamp is recorded.
* **Near-duplicate detection is not automatic** — only exact SHA-256 duplicates are merged.
* **Import is copy-only**, not move: the source file is never modified, which costs disk space
  during a large import batch.
* **Waveform buckets are 400 by default**; very long files are folded, not downsampled per
  second.

## Honest limits restated

1. **Exactly-once is not claimed.** Guarantees: no accidental duplicate within an intent, no blind
   resubmission after an ambiguity, reconciliation before any retry.
2. **Instagram cannot publish here** until a bucket exists; the state is `blocked`, not "coming soon".
3. **Provider processing time is the provider's** — the GUI shows a status string, never an invented
   percentage.
4. **Upload resumption is provider-specific**: Facebook by offset, TikTok by chunk index with an
   expiring URL, Instagram by re-uploading the delivery object and creating a new container.
5. **A live test does not prove exactly-once** either; `docs/LIVE_PUBLISHING_TESTS.md` says what it does
   prove.

## b. Decisions made

- **ADR-02 revised with evidence:** Node 26.13.1 kept (Vite 8.3.8, TS 7.0.2, Electron 45.4.1 all
  work). No LTS downgrade needed.
- **ADR-09 closed with measurements** (see `docs/ADR/README.md`): 0.6b = 75.8 tok/s (100% GPU),
  1.7b = 45.4 tok/s (100% GPU), 4b = 15.5 tok/s (69% GPU). Ollama's `cuda_v13` rejects Pascal;
  `cuda_v12` accepts it. Risk R1 closed.
- **ADR-05 enforced:** machine `TEMP`/`TMP` untouched; child processes get `<DATA_ROOT>\temp`.
- **`OLLAMA_MODELS` corrected** from a stale `D:\NEXUS_DATA\models` to `<DATA_ROOT>\models\ollama`.
- Ollama's own state (`db.sqlite`, `server.log`, ~173 KB) stays on C: because Ollama resolves it
  through the Windows Known Folder API. Documented in THIRD_PARTY.md rather than hidden.

## e. Defects found and fixed during this phase

| Defect | Fix |
|---|---|
| `git` committed 2 GB of Ollama binaries | `Programs/`, `tools/`, `*.exe` gitignored; commit amended; `.git` compacted to 214 KB |
| Electron failed: `app` undefined | `ELECTRON_RUN_AS_NODE=1` inherited from host → `launch-electron.cjs` strips it |
| UI showed "Failed to fetch" | Missing CORS allowlist → strict allowlist added to FastAPI |
| pnpm 12 blocked Electron postinstall | `pnpm.onlyBuiltDependencies: ["electron","esbuild"]` + `pnpm rebuild electron` |
| `Do` helper broke bootstrap.ps1 | PowerShell keyword collision → renamed to `Act` |
| Shell heredocs mangled backslashes | Test/doc files written with the file editor, not shell heredocs |
